# Soul Sisters Mahjong — Website Template

Built from the Soul Sisters Mahjong Brand Book v3.0. Plain HTML, CSS and a little JavaScript. No build tools needed.

## Pages
Home, Shop, Lessons (with hosted lessons and FAQ), About, Buying Guide, Favorite Finds, Free Resources, Events, Contact, Privacy Policy, 404.

## To fill in
1. `js/site.js`, top of file: Calendly link, business email, Instagram and Facebook links. Each one turns on automatically once filled in.
2. Photos: replace every striped "photo" box with real photography.
3. Products (Shop and Home): names, descriptions, prices, photos.
4. Favorite Finds: real products and affiliate links (only confirmed partners).
5. Events: real dates.
6. Lessons: confirm prices (marked "Verify") and add the cancellation policy.
7. Contact form: not connected yet. Connect it to a form service before launch.
8. Privacy Policy: add the date and have it reviewed.
